# Anki exporter fixtures

Generated by the official Anki 26.9.3 Python backend (`pip install anki==26.9.3`; run `generate.py`). All notes and media are fictional; no personal study data.

- latest-media / legacy2-media: 3 notes, 5 cards; Basic, Reversed, Cloze; Japanese parent/child deck and tags; PNG and silent WAV.
- latest-no-media: same notes, media excluded; image note must be skipped explicitly.
- latest-vocabulary-1900: 1,900 notes/cards, 19 child decks, 7 fields, heading/paragraph/hr/FrontSide template. Both audio references deliberately have no media; retain text with warnings.

Anki packages include a dummy legacy collection in latest exports. Tests must read the actual latest DB and never fall back to the dummy.

- latest-descriptor-extra: real latest exporter payload rewrapped with DEFLATE, streaming data descriptors and optional ZIP extra fields.
- expansion-limit.zst: synthetic 2 MB repeated bytes to verify streaming expansion rejection.
