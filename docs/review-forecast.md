# Issue #13 復習負荷予測・学習計画

記録 → 復習負荷予測・学習計画。7日／30日、全デッキ／選択デッキと子孫を切り替える。図の2系列と日ごとの数値は次の別の量であり、合算しない。

- **確定済み期日（枚）**：現在停止していない学習済みカードの現在のdueを1回ずつ集計。期限超過は今日へまとめ、未来のdueは学習日境界に割当。未学習カードと期間外のdueを除外。兄弟抑制で今日出題されない場合も、保存済みの期日として残す。
- **回答の見込み（回）**：今から毎日、学習日終了の1秒前に各カード1回・すべてGoodとする逐次シミュレーション。既存期日・今後の新規学習・その後の復習を含む。今日すでに回答したカードと、同日の短期繰返しを除外するため、実際の回答回数や今日の待機カード再回答とは異なる。

## 前提

全デッキで新規を作成日時・UUID順に学習する仮定。復習はdue・UUID順。全体の新規上限、祖先を含むデッキの上限と当日の消費枠、兄弟カード抑制（短期カードは例外）を使う。デッキ別表示でも全体をシミュレートして対象分だけ集計するため、他デッキの新規が全体・共有親枠を消費する。未学習の残り枚数は上限・停止状態・兄弟抑制が変わらない場合の見込み。未来の他デッキへの移動・追加・削除は仮定しない。

固定Swift-FSRSの現在スナップショットをコピーして計算する。保持率は最も近いデッキ／祖先設定、未指定時は全体設定。個人パラメータが有効なら使用する。#12の最適化履歴がなくても既定値で計算可能。fuzzなし・短期学習あり。1回／日と固定Goodは計画用の仮定であり、失敗時の再学習・追加回答・実際の回答時刻・セッション回答上限・ホームの選択条件によって結果は変わる。

日次目標は全デッキ共通の学習カード枚数の参考として表示し、予測を制限しない。時間の見込みは、対象デッキに現在割り当てられる直近30日の保存済み回答時間（0と30分超を除外）の中央値×見込み回答数。履歴がなければ表示しない。回答時間は学習中の有効時間で、問題を読む長さやカード形式・入力方式に左右される。実測や所要時間の保証ではない。

学習日境界は現在のカレンダー・時間帯と設定の開始時刻を使用する。固定24時間刻みで日を作らず、夏時間による23時間日などに対応する。回答・Undo・新規追加・設定変更を含む保存後、再訪、期間・デッキ変更、foreground復帰、表示中の学習日境界や時間帯変更で再計算する。手動更新も利用可能。

## 保存・アクセス性

SwiftDataはmain actor上で値スナップショットへ変換し、utility Taskで計算する。モデルを別actorへ渡さない。新しい計算・画面離脱で中止し、古い計算結果が後から表示を上書きしない。予測結果は保存しない。スキーマ・バックアップ形式・カードUUID・due・FSRS・ReviewLog・下書き・Undo・設定を変更しない。

図は補助とし、同じ日ごとの期日・新規・復習・時間見込みを標準行に表示する。VoiceOver用の要素をまとめ、図と数値の重複読み上げを避ける。色だけで確定値と予測を区別しない。
