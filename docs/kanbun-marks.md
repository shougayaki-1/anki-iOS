# 漢文の訓点（Issue #52）

縦書き・ルビの共通レンダラー（#51）に、漢字ごとの返り点・訓点送り仮名・再読の左ルビを追加する。面ごとの横／縦方向、入力下書き、CSVの本文、プレビューと学習表示は同じ経路を使う。本文は編集可能なテキストのまま保存し、UUID・variantKey・FSRS・due・ReviewLogを注記変更で失わない。

## 正式な記法

[青空文庫の訓点注記](https://www.aozora.gr.jp/annotation/kunten.html)に基づき、次を正式対応とする。

- 返り点：漢字の直後に `［＃レ］`、`［＃二］`、`［＃一レ］` 等。
- 送り仮名：漢字の直後に `［＃（ズ）］`。32文字以内。
- 同じ漢字には送り仮名と返り点を連続して指定できる。順序はどちらでもよい。1種類ずつに制限し、重複は警告する。
- 再読の左ルビ：`未［＃「未」の左に「ザル」のルビ］`。引用する字は直前の漢字と一致すること。32文字以内。
- 右の読み：既存の明示ルビで `｜未《いま》`。単漢字に左右の読みと送り仮名・返り点を組み合わせる。

```text
不［＃（ズ）］［＃レ］知［＃（ラ）］。
自［＃二］女王國［＃一］東度［＃レ］海千餘里。
｜未《いま》［＃「未」の左に「ザル」のルビ］［＃（ダ）］［＃レ］若［＃（カ）］［＃二］知［＃（シクシテ）］［＃一レ］。
```

返り点の許容値：レ、一、二、三、四、上、中、下、甲、乙、丙、丁、天、地、人、一レ、二レ、上レ、下レ、甲レ、乙レ、天レ、地レ、人レ。これ以外の複合記号は明示的に警告し、原文へ戻す。本文に竪点（‐）を書くことはできるが、熟語の字をまとめる機能や注記の紐付けには解釈しない。

1字の左下に返り点、右下に送り仮名、左右の上側にルビを小書きで配置する。長さから上下の余白を確保し、同じ字のルビ／送り仮名／返り点や次の漢字が重ならないようにする。注記は直前の単漢字にだけ付く。複数字のルビ全体に訓点を付けることは初期非対応。句読点、空白、改行へ注記を付けると警告する。未知・未閉鎖・不正な注記は編集前に案内し、原文全体を安全に表示する。

カード編集の「漢文の訓点」には例と、字・送り仮名・返り点・再読左ルビを入力して末尾に追加する補助を用意する。原文の任意位置の編集は標準テキスト入力で行う。再読の初回／二度目の読み、送り仮名、返り点はすべて利用者が指定する。自動の返り点生成・書き下し・OCR訓点抽出・AI生成は行わない。

穴埋めは `{{c1::不［＃（ズ）］［＃レ］}}` のように注記ごと隠す。隠した字の外に連続する注記も問題面で抑制し、送り仮名から読みを漏らさない。番号解析とカードIDは従来の規則を維持する。模範解答は既存の解答公開条件に従い、ヒント・解説の条件も変更しない。

## 表示・互換

構造化した字・注記だけを安全なHTMLへ変換する。小書きと左右配置はCSSで指定し、WebKitの特殊な注記機能やJavaScriptには依存しない。本文以外はSwiftUIのまま。外部リソース・ナビゲーション・JavaScriptの禁止と原文フォールバックは#51と共通。VoiceOverには字と注記の種類・読みを文字で提供する。英文TTSは注記を落とした本文だけを扱う。

保存モデル・バックアップ形式の追加変更はない。既存のTextContentに原文と面設定を保存し、編集下書き・完全バックアップ／復元・CSV本文でそのまま保持する。横書きも安全に表示できるが、訓点教材は縦書きを選ぶ。最低対象iOS17のコンパイルは維持し、実機の目視・最低OS実行・VoiceOver音声は別途確認する。
