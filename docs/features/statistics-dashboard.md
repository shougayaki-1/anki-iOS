# 記録ダッシュボード（Issue #100）

## 情報階層

「積み重ねた学習」→「現在の記憶」→「カレンダー」→「これからの復習」→「記憶のコンディション」→「詳細分析」。大きな装飾ヘッダーを置かず、最初の画面でユニーク学習枚数・回答時間・連続日数・今日の目標を表示する。

- `StatisticsView` が条件・読み込み・画面のライフサイクルを担当する。
- `LearningSummarySection`、`MemoryGrowthSection`、`StudyCalendarSection`、`DashboardForecastSection`、`MemoryInsightsSection` が値の表示と選択を担当する。
- 既存の `StatisticsDetailsView`（旧StatisticsView）、`MemoryAnalysisView`、`ReviewForecastView`、`AchievementHistoryView` を詳細として残す。FSRS・保存処理・達成判定は変更しない。

## 指標と対象

| 指標 | 定義・適用範囲 |
| --- | --- |
| 学習枚数 | 保存済みReviewLogのCard UUIDを期間内で重複排除。Note数でも日別枚数の合計でもない |
| 回答回数 | 正式な保存済み自己評価数。同じカードへの反復を含む。Undo済みは除外 |
| 学習時間 | 保存済みdurationMsの非負値の合計。画面では分未満切り捨て。アプリ滞在時間ではない |
| 期間 | 今日の学習日を含む7/30/90日、または全履歴。過去実績だけに適用 |
| 連続日数・日次目標 | #102のAchievementProgressを再利用。全デッキ共通。目標はユニーク枚数。条件・期間で絞らない |
| 記憶の成長 | 現在残るカード。停止カード・休止デッキ（子孫含む）を除く。New＝未学習、ReviewかつStability 21日以上＝長期定着、それ以外の学習済み＝学習・復習中。3分類は重複しない |
| 長期定着 | `MatureCards.contains` を共用。FSRS推定で永久記憶を保証しない。期限超過でも状態・Stabilityに従って分類 |
| カレンダー | 全履歴の日別実績。上部の期間には依存しない。濃淡は回答数。日付を選ぶとユニーク枚数・回答回数・時間・4評価を更新 |
| 保存済み期日 | 今日を含む7/30学習日。#13の期日バケット規則を共用。停止・休止を除外し、hiddenUntilを考慮。期限超過は今日に含む。学習後の追加復習は予測しない |
| FSRSプレビュー | 現在の想起確率の平均、安定度・難易度の中央値。実測は既存の過去30日True Retention。試行0は「—」 |

デッキは子孫を含む。複数タグはAND。ホームの学習対象は変更しない。現在の所属に基づき過去履歴を分類するため、削除済みカードの履歴は全体に残るが所属別には割り当てない。未来日時のログは除外する。

カレンダー・期間・日次目標は既存StudyDayの設定境界（既定4:00）と現在のタイムゾーンに従う。非学習日は0を表示し、途切れを責める演出はしない。

復習詳細の条件付きシミュレーションは既存#13の独立した条件画面。全Good・学習日末1回等の仮定をその画面で説明する。概要の選択条件と独立しており、タグは適用しない旨をリンク直下に明示する。保存済み期日と回答見込みは合計しない。

## データ取得と更新

`StatisticsReader`のバックグラウンドactor・materialキャッシュ・フィルター別履歴キャッシュ・達成集計を維持。既存の履歴1走査で期間別の重複排除セットと日別バケットを作り、コンパクトな値型として返す。現在のカード・期日は既存PreparedCardから作り、SwiftDataモデルをactor間で渡さない。カレンダー分のキャッシュコストも予算に加算する。

期間・日付・予測表示日数の変更は取得済み値の選択のみ。bodyでReviewLogの取得・全件集計を行わない。フィルター・データrevision・再訪・前景復帰・学習日/タイムゾーン変更で既存の世代管理付き取得を使う。読み込み中は古い条件の数値を隠してProgressViewを表示する。保存失敗は既存のエラー表示・再試行を使う。

## 操作・表現

- 学習サマリーから既存詳細へ、連続記録から達成履歴へ進む。
- 記憶分類→定義→対象カード一覧（2操作）。カード本文へは既存カード詳細を使う。
- カレンダーの月送り・日付選択は選択枠と日付つき実績を更新する。未来の月・日は無効。
- 復習の棒はSwift Chartsの選択機能を使い、日付と枚数を表示。横スクロールの日別ボタンでも同じ選択が可能で、VoiceOverから操作できる。
- 選択は既存HapticsServiceの軽いselectionを使い、off/standard/richを尊重する。
- 期間と日付の更新は200〜240ms。Reduce Motionではアニメーションなし。スクロール時の再生・常時アニメーションはない。
- 意味のある見出し、日付・数値・選択中のアクセシビリティラベル、システム色と動的フォントを使用。Light/Dark対応。

## 検証

本番ストアは使用しない。`-study-test-store <UUID> -study-test-dashboard` はDebug限定で、専用UITestStores内に英語階層デッキ・読書デッキ・複数タグ・90カード・約110日間の履歴を作る。通常起動ではfixtureを作らない。画面の数値はこのテストデータの値であり本番実績ではない。

実行結果と画像・動画はPRに記載。実機の触覚とVoiceOverの実読み上げは未検証。
