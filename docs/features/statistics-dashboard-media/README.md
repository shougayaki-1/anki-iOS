# Issue #100 UIレビュー

iPhone 15 Pro / iOS 26.5 の専用Simulator。Debug限定の隔離fixtureを使用し、本番学習データは使用していません。

- `overview.png`: 上から下までの各区間の実画面を2列に並べた一覧（長い画面を合成した架空のUIではありません）。
- `first-view.png`: 初期の7日間。
- `30-days.png`: 過去30日。日別ユニーク数を加算していないことを確認できます。
- `growth.png`: 現在の分類・割合。タップして説明と根拠へ。
- `calendar-selected.png` / `calendar-previous-month.png`: 日付選択と月送り。
- `forecast-selected.png` / `forecast-30-days.png`: 保存済み期日、選択日と7/30日切替。
- `insights.png` / `details-links.png`: FSRS推定・実測と既存の詳細分析への導線。
- `filtered.png`: 階層デッキとタグを適用した実績。
- `dark.png` / `empty.png`: Darkモードと0件。
- `interactions.mp4`: 主要操作の短い動画。

各画像はfixtureでの仮の学習実績です。録画はUI自動操作のため、画面間に待機があります。
