# Issue #4：ネイティブUI／アイデンティティ監査

実装日：2026-10-10。PR #23を前提にした独立PR。Issue #3の未確認項目を、この監査の成功扱いにはしない。

## 表示名・アセット

- 表示名は「暗記ノート」。Bundle ID `dev.shoug.AnkiIOS` と保存領域を維持する。
- インディゴをアクセントに、標準のシステム背景・フォント・SF Symbolsを使用する。
- アイコンは重ねたカードと復習の矢印を独自に図形で描いたもの。第三者のロゴ・画像素材・フォントを含めない。`tools/generate_icon.py`（Python 3 + Pillow）で1024pxの不透明PNGを再生成できる。OSがホーム画面の角をマスクする。
- `Assets.xcassets` に通常／ダークのアイコン・アクセントを管理する。塗りボタンは `PrimaryAction`、評価は `GradeAgain/Hard/Good/Easy`、設定の補助文は `SecondaryText`。塗りボタンと白文字は6.11〜7.32:1。暗い画面で明るいアクセントを塗りボタンの背景に流用しない。
- 公開時の名前の利用可否・ストア情報はIssue #21で最終確認する。外部公開はしていない。

## 検証方針

追加UIテストはデッキ追加のキャンセル、検索結果ゼロの案内、設定の表示名、文字コントラスト／クリッピング／説明を監査する。設定は上部とスクロールした下部を確認し、システムの半透明タブバーに隠れた要素や存在しない要素は現在の可視範囲の監査から除外する。既存の特大文字・ダーク・記述式回答のテストで、DEBUG限定引数により学習画面のReduce Motion分岐も通す。これはシステム設定の変更やVoiceOverの音声を確認した証拠ではない。

小型画面はiPhone SE（第3世代）／iOS 26.5シミュレーターで確認する。実機はiPhone 15 Pro／iOS 27.0.1で別途実行し、機内モード・カメラ・実通知・VoiceOver音声・触覚の実感はIssue #3の記録に明示する。

- iPhone 15 Pro／iOS 27.0.1：表示名・アイコンメタデータ・カラーの実機テスト成功。写真マスクと写真OCRの登録・学習テストも入力順変更後に成功。

## 復習優先ホーム・Issue #28〜#31（2026-10-10、日本時間）

フィルターシートは編集中の条件をStateで保持し、適用でのみ保存する。ホーム条件はExtraPreferences.homeScope、セッション条件はSessionScopeとして保存し、復元後も別々に読み込む。複数タグANDと親デッキ配下、キャンセル・リセット・再起動・中断下書き・Undo・全体進捗をテスト対象とした。

ホームは学習対象、復習CTA、再開、ほかの学習、全デッキの今日の学習の順。復習CTAは標準の全幅ボタンで、明示した文字と大きな件数を併用する。補助行の説明とフィルター要約にはSecondaryTextを指定し、ボタン内で薄いアクセント色に見える表示を避ける。復習待ちには「絞り込み後」、進捗には「全デッキ・ユニークカード」の読み上げを付ける。件数とモードの説明は読み上げ可能。固定高さ・ホーム独自アニメーションを使用せず、最大文字サイズはスクロールで操作できる。

| 更新トリガー | 読み込み | 通知 |
| --- | --- | --- |
| 起動、カード追加/編集/削除/停止、設定変更、フィルター適用、学習終了、復元 | フル読み込み、全読取成功後に公開 | 既存の差分調整 |
| ホーム復帰、ホーム表示中の15秒周期 | 同じ時刻でHomeSnapshot。当日の履歴とカード状態・対象メタデータを取得。本文表示生成・全履歴統計・保存なし | 学習日/時間帯・全体の復習枚数が変わる場合のみ |
| アプリがアクティブに復帰 | HomeSnapshot。学習画面ならキュー更新、記録表示なら統計更新 | 権限変更等も考慮して差分調整 |
| 記録タブへ移動 | HomeSnapshot＋詳細統計 | 上記の実際の変化時のみ |
| シーンが非アクティブ | 必要なセッション時間計測の保存 | 再予約しない |

読み込み失敗では最後の正常値を保持し、件数の代わりにエラー・再試行を表示する。空の開始は保存層でも拒否し、中断セッションを置換しない。待機中セッションからの新規開始にも確認を出す。目標達成は開始可否を変えない。新規上限の案内は設定した学習日開始時刻に従う。

性能の初回測定: iPhone 17 Pro / iOS 26.5 Simulator、1000ノート・3000カード・10000履歴。Store初期読み込み0.509秒、HomeSnapshot更新5回の平均0.071秒。周期更新で本文表示生成・全履歴統計・保存を呼ばず、状態不変なら通知センターの再照会をしないことを故障注入と通知センターのspyで検証した。シミュレーターの単発測定であり、実機の応答時間は未評価。

検証対象: Light、Dark＋最大Dynamic Type、コンパクトなiPhone画面の復習CTA、フィルター操作と中断、3モード、期限到来・学習日境界、エラー後の再読取、バックアップ復元後の条件・下書き・Undo、通知の差分更新、既存FSRS/履歴/バックアップ回帰。実行結果と画面確認は検証集計に記録する。

実機受け入れの残件は#3と連携する。今回の変更について、実機の機種・OSでの手動操作、VoiceOverの音声とフォーカス移動、OS設定によるReduce Motion、実際の機内モード、長時間放置での学習日跨ぎは未検証。テスト用のダーク/文字サイズ・Reduce Motion引数はOSの設定変更や音声確認の証拠ではない。以前の実機検証結果を今回のホームの検証成功として扱わない。

監査の範囲: 自動監査は現在の画面で完全に見える、識別可能な要素を対象にする。スクロールで半透明ナビゲーション/タブバーの背後に移った要素、OSがXCUIElementを返さない匿名のコントラスト/文字切れノードは自動判定から除外し、添付の画面を目視で確認する。除外はテスト添付にも記録する。VoiceOver音声・全フォーカス順の受け入れを代替するものではない。小型画面のLightで文字切れ・コントラスト・説明・タップ領域の監査に成功し、Dark最大文字サイズでは復習ボタンの省略を解消して、スクロール・フィルター・カード追加保存を確認した。

画面記録: [小型画面Light](verification/home/small-light.png)、[Dark最大文字サイズ](verification/home/small-dark-largest-type.png)、[フィルターDark最大文字サイズ](verification/home/filter-dark-largest-type.png)。最大文字サイズでは学習対象の要約を折り返し表示する。

設定画面の回帰監査では、iOS 26.5のOSコントラスト監査が、添付の黒文字/白背景の「通知時刻」等にも失敗を返した。設定画面のみ、文字切れ・説明の自動監査は継続し、コントラストはLabel/SecondaryText/AccentColorをLight/Darkのシステム背景に対して4.5:1以上と確認する数値テストと、上部/下部の画面確認に分けた。ホームのコントラスト自動監査は維持する。既存の学習画面監査は、スクロールでナビゲーションバーの背後に隠れた進捗ノードを可視領域の判定から除外する。Filesピッカーの検証は現在の表示名「暗記ノート」と、ボタン/セル両方の「このiPhone内」表現に対応した。通知のUI検証は権限ダイアログとアプリのバックグラウンド遷移完了を待ってから判定する。

最終検証集計: [ケース別結果](verification/home/test-summary.json)。修正後の対象再実行を含め、93件中88件成功・5件スキップ・残存失敗0件。単一の全件成功実行ではなく、各ケースの最新結果を集計した。スキップは実機の通知診断・カメラ・CSVと、指定写真素材が必要な2件。途中のfinal-ui実行はケース終了後のレポート集約が停止したため中断し、ログの結果を使用した。その実行の失敗ケースは後続で再検証した。iPhone 17 Pro Simulatorの通知配信→タップ→学習→OFF→再起動、小型画面の適用/リセット/モード切替取消、色の数値テストは最終再実行で成功。Releaseのarm64 Simulatorビルドも成功した。
