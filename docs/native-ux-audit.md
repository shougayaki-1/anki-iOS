# Issue #4：ネイティブUI／アイデンティティ監査

実装日：2026-10-10。PR #23を前提にした独立PR。Issue #3の未確認項目を、この監査の成功扱いにはしない。

## 表示名・アセット

- 表示名は「暗記ノート」。Bundle ID `dev.shoug.AnkiIOS` と保存領域を維持する。
- インディゴをアクセントに、標準のシステム背景・フォント・SF Symbolsを使用する。
- アイコンは重ねたカードと復習の矢印を独自に図形で描いたもの。第三者のロゴ・画像素材・フォントを含めない。`tools/generate_icon.py`（Python 3 + Pillow）で1024pxの不透明PNGを再生成できる。OSがホーム画面の角をマスクする。
- `Assets.xcassets` に通常／ダークのアイコン・アクセントを管理する。塗りボタンは `PrimaryAction`、評価は `GradeAgain/Hard/Good/Easy`、設定の補助文は `SecondaryText`。塗りボタンと白文字は6.11〜7.32:1。暗い画面で明るいアクセントを塗りボタンの背景に流用しない。
- 公開時の名前の利用可否・ストア情報はIssue #21で最終確認する。外部公開はしていない。

## タスク別レビュー

| 画面／操作 | 判断と対応 |
|---|---|
| ホーム | 復習・新規・混在、再開を標準Listに維持。目標達成後も続けられる導線を保持。独自ダッシュボードに置換しない |
| ライブラリ | 検索対象にタグを案内。空のライブラリと検索結果ゼロを別の文言にし、登録方法と検索の修正方法を示す。既存のタブ・NavigationStackを保持 |
| デッキ追加 | キーボード表示中でも「キャンセル」で戻れる導線を追加。キャンセルした未保存デッキを作成しない。既存デッキ編集は標準の戻る操作を使用 |
| ノート追加／編集 | 問題・解答を画像やタグより先に配置し、主要入力へ早く到達できるようにする。保存は確認して確定。「閉じる」は下書きを保存する既存仕様とアクセシビリティヒントを維持。明示的な下書き破棄は確認する |
| 一括登録／OCR | 入力→プレビュー→確認→結果の順序を保持。結果の件数と行エラーを表示。OCR結果は手直し後に確定する。長いプレビューでも確定操作は画面下に固定 |
| 学習 | 全画面・答え表示後の4評価・Undo・中断を保持。評価は文字ラベルと色を併用。白文字の背景を各色で十分暗くしてライト／ダークのコントラストを改善。特大文字はPR #23の明示メニューを使用 |
| 記録 | 学習枚数と回答回数を区別した標準Listを維持。詳細グラフはIssue #9で扱う |
| 設定／バックアップ | アプリ名・端末保存・バックアップの案内を追加。小型画面の監査で薄い補助文と見出しが指摘されたため、補助色と見出しの強調を改善。通知許可は明示的なON操作時だけ要求。置換復元は検証・確認・元ストア保護を維持 |
| エラー／削除 | 既存のalert／confirmationDialogとdestructive roleを使用。失敗時に成功として画面を進めない。学習履歴を不要に消す変更を加えない |
| 動作と触覚 | 答え表示・カード遷移の0.18秒アニメーションはReduce Motionで無効。触覚はStudyStore側の確定アクションに集約した既存仕様を保持し、Viewに二重発火を追加しない |

## 検証方針

追加UIテストはデッキ追加のキャンセル、検索結果ゼロの案内、設定の表示名、文字コントラスト／クリッピング／説明を監査する。設定は上部とスクロールした下部を確認し、システムの半透明タブバーに隠れた要素や存在しない要素は現在の可視範囲の監査から除外する。既存の特大文字・ダーク・記述式回答のテストで、DEBUG限定引数により学習画面のReduce Motion分岐も通す。これはシステム設定の変更やVoiceOverの音声を確認した証拠ではない。

小型画面はiPhone SE（第3世代）／iOS 26.5シミュレーターで確認する。実機はiPhone 15 Pro／iOS 27.0.1で別途実行し、機内モード・カメラ・実通知・VoiceOver音声・触覚の実感はIssue #3の記録に明示する。

## 実行結果

- iOS 26.5シミュレーター：単体・結合61件成功。設定、バックアップ、保存、FSRS、画像の既存回帰とアセット・塗りボタンのコントラストを含む。
- iPhone SE（第3世代）シミュレーター：特大文字・ダーク・記述式回答・Reduce Motion分岐、登録→学習→Undo→再起動→編集→削除、入力下書きの再起動復元が成功。追加の表示名・デッキ作成キャンセル・検索結果ゼロ・設定監査も成功。
- 設定監査はNavigationBarとTabBarの間に完全に収まる、存在して操作可能な要素を対象とする。OSが要素を紐付けず返したコントラスト指摘は記録して除外し、添付した上下のスクリーンショットを目視確認した。画面全体の全OS要素に対する監査成功とは扱わない。
- iPhone 15 Pro／iOS 27.0.1：表示名・アイコンメタデータ・カラーの実機テスト成功。写真マスクと写真OCRの登録・学習テストも入力順変更後に成功。
- VoiceOver音声、触覚の実感、システム設定によるReduce Motion切替、iOS 17の実行は未確認。Issue #3の残件とともに引き続き確認する。このためIssue #4の完了条件すべてを満たしたとは記録しない。
