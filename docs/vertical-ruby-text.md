# 縦書き・ルビ（Issue #51）

カード編集の「本文の表示」で問題面・解答面を個別に横書き／縦書きにする。既存カード、既存CSV、設定が欠落した下書きは横書き。縦書きは上から下、列は右から左。長文は本文領域内を左右にスクロールし、横書きのルビ付き長文は領域内を上下にスクロールする。本文の選択・コピーはWebKitの標準操作を使う。通常の横書き本文は従来のSwiftUI Textで表示する。

ルビは明示的に `｜漢字《かんじ》`（ASCII `|` も可）と入力する。親文字の範囲を省略する青空文庫の暗黙ルビは初期対応外。「ルビを末尾に追加」で親文字と読みを入力でき、複雑なHTMLを書く必要はない。例：

```text
｜春暁《しゅんぎょう》
春眠不覚暁。12年の記録。
｜東京《とうきょう》へ行く。
```

縦中横は独立した2桁数字を自動で組む。3桁以上、明示的な縦中横マークアップ、漢文の返り点・送り仮名・再読文字は初期対応外（漢文の訓点は #52）。句読点・括弧・英数字の字形はiOSの日本語システムフォントとWebKitの縦組みに従う。

穴埋めと併用する場合は `{{c1::｜東京《とうきょう》}}` のように親文字と読みを同じ穴埋めに含める。穴埋め番号とUUIDは従来どおり維持する。`｜{{c1::東京}}《とうきょう》` のように対象の外に読みがある場合も、問題面では対応する読みを抑制して答えを漏らさない。裏表反転では原文とともに面ごとの方向を交換する。ヒント・解説の公開条件は変更せず、横書きのまま。

入力不備、空の親文字・読み、未知の暗黙ルビは編集画面と本文に案内を出し、原文全体へフォールバックする。保存可能な原文は失わず、HTML文字も本文として表示する。解析対象の上限はUTF-8で200KBで、それを超えるルビ本文も原文表示へフォールバックする。HTML/CSSはエスケープしたトークンから生成し、JavaScriptを無効化し、CSPとナビゲーション制御で外部通信・外部リソース・リンクを禁止する。本文表示はオフラインで完結する。

## 保存・取込互換

TextContent／NoteInputのOptional `questionLayout`／`answerLayout`へ保存する。値は `horizontal`／`vertical`。SwiftDataモデルの変更は不要。編集下書き、保存、再起動、完全バックアップ／復元で保持する。方向変更やルビ修正でカードUUID・variantKey・FSRS・due・ReviewLogを保持できる。学習済みの文章変更時は既存の復習予定維持／明示リセットの選択を使う。

CSV／TSVはヘッダーに `question_layout`（または問題表示）と `answer_layout`（または解答表示）を追加できる。値は `horizontal`／`vertical` または横書き／縦書き。空欄・列なしは新規では横書き、既存更新では現在設定を保持する。不明な値は行エラーとして取り込まない。ヘッダーなしの従来の問題／解答列取込は変更しない。

```csv
question,answer,question_layout,answer_layout
｜春暁《しゅんぎょう》,春の明け方,vertical,horizontal
```

プレビューと学習は同じレンダラーを使い、解答本文は既存の解答公開状態に従って初めて生成する。VoiceOverには本文と読みを意味のある文字列で提供する。英文TTSはルビ記号ではなく親文字を読み、穴埋めの非公開箇所は従来どおり読まない。

iOS 17以降を対象にコンパイルする。最低OSの実行・実機の禁則とルビ位置・VoiceOverの音声は別途目視／聴覚確認が必要。拡大文字・iPhone SE試験は利用者の指定で省略する。
