# App Shortcuts（Issue #18）

iOS 17以上、Apple App Intents / App Shortcuts、ローカルSwiftDataを利用します。

## 使い方
1. アプリを一度起動し、iOSの「ショートカット」アプリでアクションを追加します。
2. 「暗記ノート」を検索し、「復習を開始」「新規学習を開始」「学習進捗を見る」「指定デッキを開く」から選びます。
3. 「指定デッキを開く」ではフルパスで区別されるデッキを選択します。Siriでもアクション名で起動できます（言語設定に依存）。

## 挙動と安全性
- 復習／新規学習は保存済みのホームフィルターと上限、既存の `StudyStore.start` / `resume` を利用します。対象0件ではセッションを作成しません。
- 中断セッションを優先します。待機・完了待ちのセッションは破棄せずホームで案内します。モード変更にはホームで明示操作が必要です。
- 進捗は既存の「記録」タブ。今日のユニークカード数・回答回数を表示します。セッション単位の回答数とは異なり、#9の新統計実装には依存しません。
- デッキはUUIDで選択し、親子を含むフルパスを表示します。開いた先には下位デッキのカードも含みます。削除・復元後はIDを再検証し、安全にエラー表示します。
- アクションは端末のアプリを開くだけで、カード採点・削除、FSRS、学習ログを直接変更しません。外部サービスは不要です。
- 起動前の要求はローカルUserDefaultsで一時保存し、UI準備後に一度だけ消費します。ロック中・未起動はOSの解除操作およびファイル保護状態に従います。

- UI: ショートカットルーティング、記録タブとデッキ画面。手動のSiri起動、ロック・バックグラウンド、VoiceOver、最大Dynamic Typeは**実機未検証**。
