# ノート数・カード枚数・処理行数

ライブラリの登録数はノートIDの種類数とカードの実数です。検索時には全体と表示中を併記します。ノートは問題・解答のまとまり、カードは出題単位です。反転、異なる穴埋め番号、画像マスクから複数枚を生成できます。編集とプレビューの枚数は実際の CardGeneration.variants で算定します。

一括登録の「処理」は成功した入力行数です。「新規ノート」「更新ノート」「新規カード」「維持したカード」は各UUIDの種類数であり、同一対象を複数行で更新しても1件です。同一バッチで新規作成後に更新したノートは新規に数えます。重複スキップ、利用者が除外した行、エラー行は別表示します。CSV/TSVと画像ZIPで同じ意味です。

状態は未学習、学習中、復習待ち、再学習中と表示します。復習待ちはFSRSの状態名であり、期日到来を保証しません。停止、未来の期日、対象範囲・新規枠・兄弟カードの同日抑制を説明します。登録枚数と今日のユニーク学習枚数、延べ回答回数は別です。

FSRS、既存due、永続モデル、バックアップ形式は変更しません。ノート削除の確認には削除される兄弟カード枚数を表示し、過去の回答履歴を保持します。
