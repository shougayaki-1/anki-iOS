# 問題・解答への音声添付（Issue #69）

ノート編集の「添付音声」で問題面・解答面にそれぞれローカルファイルを選択する。基本（逆方向を含む）、記述、穴埋め、画像遮蔽で共通。選択後に試聴・停止・解除できる。逆方向カードでは問題と解答の音声も交換する。穴埋め問題の録音に正解が含まれないよう、作成者が確認する。

学習の「問題を再生」「解答を再生」は添付音声を優先する。解答の音声は解答公開後のみ。英文は「TTSで読む」から明示的に切り替えられる。自動再生は従来のデッキ・カード設定を使用し、初期値はオフ。VoiceOver使用時は自動再生しない。欠損・破損時は通知して、回答・評価を継続できる。カード切替、Undo、一時停止、画面を閉じる、アプリ非アクティブ、音声割り込み・出力変更で停止する。

## 保存と互換性

- WAV、M4A（M4A/M4Bブランド）、MP3、AAC、CAF。20,000,000バイト・600秒以内、8〜96kHz、1〜2チャンネル。選択と復元時に全フレームをデコードして検証する。WAVはRIFFサイズ・各チャンク境界も検証する。
- 元ファイルのバイト列を変換せず、アプリ内Media/audioに保存。外部URLに依存せずオフライン再生できる。同一SHA256・MIME・実ファイル内容の一致で重複を再利用する。
- TextContentとNoteInputの任意UUID questionAudioID/answerAudioIDで参照する。旧ペイロードの両フィールドはnil。既存MediaAssetのMIME/ハッシュを利用し、音声のwidth/heightは0。SwiftDataスキーマ変更は不要。
- 音声のみの変更はカードUUID・FSRS・ログを保持する。ノートと編集下書きの全参照を残し、未使用メディアの掃除は画像と音声に対応する。保存失敗時は新規ファイルを削除する。
- 音声付きバックアップのmanifest.schemaVersionは2。旧版が未対応音声を黙って復元しないための変更。画像のみは1を継続し、この版は1/2を復元できる。manifest1に音声を混入したものは拒否する。データスナップショットschemaVersionは1のまま。
- 将来のデッキ交換・apkg取込でもAudioEncodingPolicyの制約とメディア参照を利用する。CSVにはバイナリ音声を含めない。
