# CSV / TSV + 画像ZIPの取り込み（#22）

ライブラリ → 一括登録 → ファイル選択でZIPを選びます。画像サムネイル、解答、デッキ、タグ、重複候補、行エラーを確認し、不要な行を除外して「確認して取り込む」→「確定して保存」。閉じるだけなら何も保存されません。

ZIPの直下に `cards.csv` または `cards.tsv` を1つ置き、画像を `images/` に置きます。表はUTF-8（BOM可）。既存の引用符・複数行処理を共用します。ヘッダーは英語の `answer,image` が必須、`question,explanation,tags,deck` が任意です。列順は自由、重複ヘッダーは拒否します。`tags` は `;` または引用符内の `,` 区切り、`deck` は `社会/地理` のような階層で、存在しないデッキを確定時に作成します。空欄なら画面で選んだデッキを使います。

問題が空欄なら共通の「画像を見て答えてください」を補います。行ごとにプレビューで問題・解答を変更できます。画像・解答は必須。通常のbasicカードとして作られ、画像表示、4段階評価、Undo、復習を既存の経路で行います。

重複は同じデッキ・問題・解答・画像内容で判定し、スキップ / 別ノート追加 / 既存ノート更新を選べます。更新は解説・タグのみを変更し、カードUUID、FSRS、回答履歴、回答方式を保持します。同じ画像はMediaAssetを共用します。既存の完全バックアップ・復元・不要画像清掃の対象です。

## 上限と対応形式

- ZIP全体・展開後総量200MB、1000エントリ（ディレクトリ含む）、1ファイル20MB、表10MB、表1万行、各ファイルの圧縮比100倍まで。
- PNG / JPEG (`.png`, `.jpg`, `.jpeg`)。ファイル名だけでなく実データを既存ImageEncodingPolicyで検証します。透過PNGはPNGのまま保持。画像は既存の40MP制限にも従います。HEICは今回未対応。
- 無圧縮 / Deflate ZIP、UTF-8名、ディレクトリ・コメント・標準データ記述子に対応。暗号化、ZIP64、シンボリックリンク、分割ZIPは未対応。
- 絶対パス、`..`、空のパス要素、バックスラッシュ、制御文字を拒否。Unicode正規化・大小文字によるファイル名衝突、CRC不一致、重なり・欠落したZIPレコードを拒否します。ZIPのパスをファイルシステムに展開しません。
- プレビューはメモリ内のみ。確定時はDBの1トランザクションで保存し、容量不足などの失敗では作成した画像を除去します。終了直前のプロセス停止で残る孤立画像は既存メディア清掃で回収できます。

画像URL取得、AI認識、xlsx、同期は行いません。単独CSV/TSV/TXT、完全バックアップ、apkg、デッキ共有とは別の入口です。

## サンプルの作成

`python3 docs/samples/create-image-zip.py /tmp/image-sample.zip` を実行し、生成されたZIPをFilesに渡します。Python標準ライブラリのみで、透過背景の細線の円と十字を作成します。公式地図記号ではなく動作確認用の独自図形です。実データでは利用できる画像を `images/` に入れ、表の `image` に一致する相対パスを記載します。
