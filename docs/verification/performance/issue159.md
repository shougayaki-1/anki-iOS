# #159 インポートの軽量化

CSVの重複判定を取込中の索引へ置き換え、ノート取得・本文デコード・同じタグID取得の反復を削減した。画像ZIPもデッキ/問題/解答/画像ハッシュの索引を使う。更新カードはnoteIDで取得し、UUID・FSRS・履歴を保持する。新規挿入も索引へ反映するため同一バッチ内の重複を判定できる。保存は従来どおり1回のトランザクションで、失敗時は全ロールバックと作成メディアの削除を行う。

CSVパーサーはCharacter配列と改行置換コピーを作らず、1文字先読みでCRLF/CRを扱う。ファイル選択の読取・UTF8変換・ZIP検証はキャンセル可能なutility Taskへ移し、画面/要求世代を確認してから反映する。画像ZIPでは参照される画像だけを検証・保持するが、未参照エントリのZIP構造・CRC・展開上限検証は維持する。

.studydeck/APKGの共通確定処理は、空タグでfetchせず、同じタグ配列のIDをトランザクション内だけ再利用する（最大128組）。APKGの圧縮バッファを早期解放する試行は1,900ノートの計測で改善が見られず撤回した。既存のバックグラウンド読取、ZIP/SQLite/Zstd上限、原本保存・バックアップ形式は維持する。
