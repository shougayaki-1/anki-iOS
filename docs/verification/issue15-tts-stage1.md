# Issue #15 — TTS先行PRの検証と制約

## 実装範囲
- iOS AVSpeechSynthesizer / en-US・en-GB 選択と利用可能な英語音声へのフォールバック
- 速度3段階、デッキ初期オフ・カードvariant別上書き、ノート別問題面/解答面テキスト
- 問題表示時と解答公開時の自動読み上げ、表示済み面の手動再生/停止、セッション単位の一時オフ
- 音声キューをカード/面変更、Undo、中断、画面離脱、バックグラウンド遷移で停止
- 日本語混在を自動で読まない、穴埋め伏せ字の音声漏えい防止。VoiceOver中の自動読み上げ停止
- 既存の StudyOptions / TextContent JSON に任意フィールドを追加。DBスキーマ、カードID、FSRS/ReviewLog、バックアップZIP構造は不変

## コードで用意した検証（Xcode未実行）
- SpeechReadoutTests: 英語判定・日本語混在・穴埋め・逆向き・版下互換・設定JSON roundtrip・デッキ/カード優先順位。
- SpeechRepositoryTests: デッキ設定の永続化、カードvariant別音声設定、学習後に音声設定だけ変更してもFSRS/ReviewLogとカードUUIDは不変、バックアップに音声設定が含まれること、CSVで取り込んだ英文。
- SpeechUITests: 手動「問題を再生」の表示、未公開の「解答を再生」の非表示、公開後の手動再生・停止、中断でホームに戻れること。
- App/Unit/Integration の Xcode ビルドと XCTest は現環境で未実施。**パスしなければReady for Reviewに変更しない。**

## iOS Simulator / 実機で必要な検証
1. 旧ストア・旧編集下書き・旧バックアップを開き、既定では一切自動再生されず、既存履歴が消えないこと。
2. デッキ「問題面のみ」「解答面のみ」「両面」とカード個別「オフ」を組合せ、自動/手動再生を確認。
3. 英文が問題面では表示と同時に、解答面では「答えを表示」後だけ鳴ること。Undo・前後カード切替・中断・再開・再描画・連打時に音声が重複しないこと。
4. 日本語混在、穴埋めヒント、複数クローズ、reverse、長文、記述式、画像マスク、入力中で未公開の答えを先読みしないこと。
5. en-US/en-GBの声、速度3段階、未インストール音声・英語音声なし、端末オフライン、サイレントスイッチ、音量ゼロ、Bluetoothイヤホンと出力先切替、着信割り込み、バックグラウンド。
6. VoiceOverオンで自動再生が止まり、手動ボタンは利用できること。iPhone SE相当、最大Dynamic Type、Dark/Light、キーボード表示中のタップ。
7. バックアップ/復元を一往復してデッキ/カードの設定とカードUUID/復習履歴を比較。
