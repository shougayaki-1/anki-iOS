# 毎日の積み重ね Widget (#231)

Smallは連続学習日数と今日の学習済み状態、Mediumはそれに直近7学習日の曜日・日付・実施マーカーと日次目標を表示する。目標オフ時はゲージを出さず今日の枚数を表示する。未学習・中断に警告色や罰の表現を使わない。学習済みは塗りつぶしの炎とチェック、未学習は輪郭で区別する。共通PrimaryAction色とシステム背景を使用する。

## 正本とデータ保護

アプリ側の保存済みReviewLog（正式なgrade 1〜4）のみを読む。直近7日を取得し、既存AchievementProgress.calculateで今日のユニークカード数と実施状態を計算する。連続日数は既存consecutiveAchievementDaysのoccupied-day probeを再利用し、7日を超える連続も保持する。全履歴・全カードの追加取得はしない。Widget用の追加集計は既存publisherのキャッシュ判定後のみ行う。

学習日の開始はStudyDayと設定値（既定4時）に従う。今日未学習でも昨日までのStreakを表示し、Mediumでは「昨日までの積み重ね」と明示する。同一カードの再評価は今日1枚、同日の複数評価で日数は増えない。閲覧・答え表示には保存処理がない。FSRS、ReviewLog、Achievementの保存・Undo・復元仕様やスキーマに変更はない。

## 共有・更新

既存App Groupのatomicなprogress-v1.jsonに任意のstreakDaysを追加した。8日分の集計済み値のみで、ID・履歴は含めない。旧JSONはnilとして読み込み、既存Widgetを継続表示する。新Widgetは更新案内を表示する。ExtensionはSwiftDataを参照しない。

既存の保存成功後・Undo・復元・設定変更・アプリ復帰のpublisher経路で3種類のWidgetへreload要求する。失敗時は学習DBに影響しない。OSが更新時刻を決めるため即時更新は保証しない。失敗後に直前の保存済みスナップショットが期限内で表示される可能性がある。

Timelineには現在・将来の学習日境界・共有データの期限を含める。境界後は今日の枚数を0にし、前日に学習済みなら昨日までの連続を1日維持、さらに1日空いたら0にする。未来の学習を推測しない。期限切れやタイムゾーン不一致では更新案内に切り替える。時間帯変更後はアプリを開いて新しい境界で再集計する必要がある。リロードは期限後、データなしでは1時間後に要求し、高頻度更新は要求しない。

学習済みのタップは既存progressリンク、未学習・空状態はhomeリンク。直接セッションを開始せず既存セッションを保持する。

## UX評価

数値と今日のチェックが主役で、7日分のチェックが日々の蓄積を見せる。未学習時は「今日の1枚から」と再開しやすくする。目標達成はチェック付きの控えめな文言で伝え、アニメーションや達成強制を加えない。祝福の全画面演出は既存アプリ内のまま。
