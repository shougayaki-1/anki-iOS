# デッキ別学習設定（Issue #7）

ライブラリのデッキ管理→デッキ編集で新規上限（0〜500枚）と目標保持率（80〜97%）を指定する。指定をオフにすると未設定となる。古いデータは全体設定を利用し、既存モデルの移行は不要。

保持率は自デッキ→最も近い親→全体の順に解決する。次の正式な評価から使い、設定だけで保存済みFSRS・due・履歴を変更しない。新規上限は自デッキとすべての祖先の指定値を独立した上限として適用し、全体枠も超えない。親上限は子孫全体で共有し、子が大きい値を指定しても親上限は解除しない。0枚は新規だけ停止し、期限到来の復習・短期学習は継続する。

日境界は既存の午前4時。新規回答の消費はカードごとに当日の最初の正式評価で数え、Undoで戻す。新しい消費記録は回答時点のデッキと祖先を保持する。カードやデッキの移動・削除で使用済み枠を復活させない。改名は設定を保持し、移動後の新しい回答には移動後の祖先を適用する。削除したデッキの上書き値は削除するが、使用済み枠とReviewLogは保持する。機能導入前の履歴は現存カードの現在のデッキから集計し、すでに削除された旧カードのデッキは復元できない（全体新規枠は引き続き消費する）。

ホーム件数、3学習モード、開始・次カード・評価時に同じ上限を適用する。デッキ・タグによる絞り込みでも使用枠は共有する。兄弟抑制、新規順序、停止、セッション上限を維持する。デッキ編集には保存済みの実効保持率と最も厳しいデッキ上限を表示する。

StudyOptions内のOptionalな上書きと消費記録を完全バックアップへ含める。不正な値・重複デッキID・履歴と結び付かない消費記録を復元前に拒否する。設定とデッキ名・親変更は一度のsaveで確定し、失敗時にrollbackする。
