# iPad対応

iPadOS 17以上。アプリ・テストの対応端末をiPhone/iPadにする。iPhoneの縦向きタブUIを維持し、iPadは全方向とマルチタスクを許可する。

## 操作

NavigationSplitViewのサイドバーからホーム・ライブラリ・記録・設定、階層デッキを選ぶ。デッキ選択は子孫のカードも含むライブラリ表示だけを絞り、学習対象設定を変更しない。デッキからの新規作成は選択したデッキを初期値とする（既存の下書きがあれば下書きを復元）。削除したデッキの絞り込みは解除する。

サイドバーは画面幅に応じて自動的に折り畳まれる。狭い分割表示ではナビゲーションのサイドバーボタンから開く。学習内容・評価ボタンは最大760pt、編集フォームは最大820ptに収める。マスクの座標は端末に依存しない正規化座標を維持し、ポインターによるドラッグと数値入力・スライダーを使える。

外付けキーボード: ⌘1〜4で画面切替、ライブラリで⌘Nで追加、編集で⌘Sで保存・Escで下書きを保持して閉じる。学習で⌘Returnで解答表示、解答表示後に⌘1〜4でAgain/Hard/Good/Easy、⌘ZでUndo、Escで中断する。評価は通常ボタンと同じ正式評価処理を通る。

## 保存・OS差異

SwiftData、FSRS、ReviewLog、4形式、メディア、OCR、バックアップ処理はiPhoneと共通。バックアップの端末間移行は明示した復元操作を使い、クラウド同期を導入しない。Files・写真選択はOS標準UI。カメラは利用可能性とアクセス権を確認し、非対応シミュレーターでは案内する。OCRはローカルVisionを使用する。

外部画面への独立した学習画面は提供せず、OSが提供するミラーリング・Stage Managerの通常ウィンドウを使う。複数画面で並行評価しない。iPadの実機カメラ、Stage Manager・Split Viewの実操作、ポインター・外付けキーボード、VoiceOver読み上げ、iPadOS17実行は別途確認が必要。拡大文字/iPhone SEのテストは依頼により省略。

## 検証結果（2026-10-11）

iPad Pro 13インチ（M5）/ iPadOS 26.5シミュレーターを明示して検証。共通の単体・結合166件成功（既存の実機専用1件スキップ）。ローカルVisionの英語・日本語OCR、4形式の生成、SwiftData移行、バックアップ保全を含む。UIでは画像マスクカードの編集・回転・学習・Undo・記録移動、7枚の4形式を縦横向きで学習、階層デッキの絞り込み、アクセシビリティ説明の自動監査、Filesへの書出し→同ファイルの検証・復元→再起動後のカード・履歴保持を確認した。詳細画面を開いた後のサイドバー切替で古い詳細が残る問題を修正した。

iPhone 17 Pro / iOS26.5の通常サイズでも共通166件と作成・学習・Undo・再起動・編集・削除のUI回帰が成功。実機受入#3の未完了と前述のマルチタスク・入力機器・VoiceOver実操作の未確認を理由にDraft PRとする。
