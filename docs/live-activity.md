# 学習セッションのLive Activity（#233）

既存Widget Extensionに`StudySessionActivity`を追加。共有するのはセッション識別子、モード、保存済み進捗、一時停止状態だけ。問題・答え・デッキ名・学習時間は共有しない。タイトルは常に「暗記学習」。PrimaryAction色を基に、暗い背景では明るい青を使用する。

## 同期とデータ保護

- Repositoryの`sessionProgress()`と`presentation()`が正本。固定復習は#212の開始時セット件数を分母とし、各カード1回の評価を「枚」で表示する。
- 新規・混合・旧形式は正式評価ログ件数を「回答」で表示。同じカードの再評価も1回答。分母は保存済み回答上限、無制限は分母もバーも表示しない。
- 新規・混合の学習画面も分母を回答上限に統一し、「上限まであと○回答」「○回答 / 上限○回答」と表示する。固定復習は「残り○枚」「今回○ / ○枚」、無制限は記録した回答数だけを表示する。以前の候補枚数による伸縮する推定値は使わない。候補が尽きた場合は従来どおり上限前に完了できる。
- 開始・評価・Undo・中断／再開・終了の保存成功後に同期する。表示読取に失敗した場合はActivityを終了させる方向に倒す。保存トランザクションやFSRS計算、スキーマには組み込まない。
- Coordinatorが非同期APIを直列化。保存済みSessionDraftの永続IDをキー順固定JSONで識別し、一致する1つを残して他を終了する。OSにより終了済みのActivityは再利用しない。旧Activityの終了が反映されない間は新規開始しない。
- 開始失敗は学習処理へ伝播させない。OS認可がない場合は開始しない。update/endは非throwing APIであり、API復帰を実表示の成功とは扱わない。次の必要イベント／復帰で再照合する。
- バックグラウンドは一時停止。強制終了などで中断通知が届かなかった場合も、60秒のstaleDate以降は「再開できます」と表示する。Timer・経過時間・ネットワーク・pushは使用しない。
- 完了判定時に即時dismissalで終了。最終回答のUndoで未完了に戻ったときは再同期する。実際の除去時刻・表示可否はOSが決定する。

## 再開と設定

`ankistudy://session/resume?id=…`は一致する未完了の既存セッションだけを再開する。新規開始はしない。終了済み／別セッションのリンクはホームを選び、Activityを照合する。完了後のUndo用下書きが残る場合もリンクから復活させない。

設定の「学習の進捗を表示」は端末のUserDefaultsに保存し、初期値はオン。個人端末の進捗表示として、他の自動表示と同様に開始時から利用可能にし、内容を匿名化する。OS認可とは独立し、オフで既存Activityを終了する。オフ／OS不許可でも学習・保存・Undoは通常どおり利用できる。

## Apple仕様と確認範囲

Context7と[ActivityKit公式仕様](https://developer.apple.com/documentation/activitykit/displaying-live-data-with-live-activities)、[DynamicIsland公式仕様](https://developer.apple.com/documentation/widgetkit/dynamicisland)を参照。通常の開始はフォアグラウンドのみ。Activityは最長8時間、終了後のロック画面残留は最長4時間というOS制約があるため、完了時は`.immediate`を指定する。4KB以下の小さな状態だけを渡す。

実行結果・代表画像はDraft PRに記載。PRレビュー（5532934398）で、ユーザー本人によるDynamic Island・ロック画面等の実機確認済み報告を受領。実機未確認を理由とした保留は解除。個別の表示形態・操作・写真の詳細は追加提供されていないため、全項目を個別に検証済みとは記載しない。表示文言修正の再レビューまでDraftを維持し、マージ・Issue Closeは行わない。
