# 苦手カードと重点練習（Issue #8）

ライブラリ→「苦手カード・重点練習」で確認する。初期期間は30学習日。7／30／90日／全期間、デッキ（子孫含む）、複数タグ（AND）で絞り込む。期間は既存の午前4時の日境界を使い、未来の回答は除外する。

## 選出基準

停止中と未学習は候補から除外する。選択期間内に少なくとも1回答を持つカードについて、次のどれかを満たすと選出する。

- 期間内の直近評価がAgain
- 期間内のAgainが2回以上
- 期間内に3回答以上あり、Again比率が30%以上
- 期間内に3回答以上あり、現在のFSRS難易度が8以上（10点満点）
- 期間内に3回答以上あり、現在の推定想起確率が75%未満

該当した理由をすべて表示する。Again回数＋Again比率×3＋直近Againなら3＋難易度÷10＋（1−推定想起確率）で並べ、同点はカードUUID順とする。難易度と想起確率は現在の状態から計算し、期間内回答に対するAgain比率とは区別する。これらは学習支援用の基準であり、正誤の保証やFSRSの再最適化ではない。

## 練習と正式評価

「重点練習を始める」で候補を再取得し、停止・削除・編集後の状態を確認する。問題、任意ヒント、解答、解説、画像・画像マスクを既存の表示内容で確認する。前／次のカードへ移動し、終了できる。並び替えやタイピングの正式な回答方式はホームの学習で使用する。

練習は画面内の一時状態だけを持つ。早期復習によるFSRS更新を行わず、due・ReviewLog・今日の学習枚数・新規枠・統計・保存済みセッションとUndoを変更しない。4段階評価ボタンも出さない。通常の学習はホームから行う。練習を終了・強制終了した場合は保存せず、一覧から改めて開始する。

兄弟抑制オンでは、その日に別の兄弟を正式評価済みのカードを練習から除外し、練習内でも1ノート1枚に絞る。learning／relearningは既存仕様に合わせて例外とする。オフでは兄弟を制限しない。苦手一覧は理由を確認するため兄弟をすべて表示するので、一覧件数と練習枚数が異なる場合がある。

保存モデルやバックアップ形式の変更はない。推定と履歴の読み取りは端末内だけで行う。画像欠落は案内を表示し、元データを変更しない。

## 練習完了（Issue #95）

最後の解答を確認して「次のカード」を押すと、チェックアイコン、実際の練習枚数、開始時のデッキ・期間・タグ条件を表示する。「同じカードをもう一度練習する」は取得済みカードと選択順を維持し、先頭・解答非表示に戻す。「苦手カード一覧に戻る」で一覧へ戻れる。FSRS・回答履歴・復習予定を変更しない旨を完了画面にも表示する。空のカード集合は完了扱いにせず、中途終了は結果を保存・表示しない。
