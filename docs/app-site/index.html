覚える毎日に、
頼れるノートを。

自分のカードをつくり、ちょうどよいタイミングで復習する。暗記ノートは、端末内に学習データを保存する暗記アプリです。

お困りのことはありますか？

不具合や使い方については、メールでお問い合わせください。

メールで問い合わせる

anki@shoug.org

アプリとiOSのバージョン、問題が起きた操作、表示されたメッセージをお知らせください。学習データやバックアップ全体の送付は必要ありません。

大切な学習データのバックアップ

機種変更やアプリの削除の前に、「設定 → バックアップ・復元」から完全バックアップ（.studybackup）を書き出し、Macなど端末外にも保存してください。デッキ共有用の.studydeckは、完全バックアップの代わりにはなりません。

バックアップは暗号化されていません。個人情報が含まれる場合は、保存先と共有先にご注意ください。問題が起きたときは、アプリを削除する前にお問い合わせください。

アカウント登録は必要ですか？

アカウント登録は不要です。カードや学習履歴は端末内に保存します。

プライバシーについて

学習データ、画像・音声、アクセス許可の取り扱いは、プライバシーポリシーをご確認ください。
