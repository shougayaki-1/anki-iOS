# デッキ単位の学習休止（Issue #174）

デッキ管理のコンテキストメニューとデッキ編集の「学習の休止」から切り替える。休止中でもライブラリで検索・閲覧・編集・移動・書き出しできる。学習中のデッキを先に並べ、ライブラリの休止中の最上位デッキを折りたたみ欄にまとめる。学習中の親に属する休止した子は親の階層に残し、既存の開閉操作を使う。

## 状態と学習対象

自分または祖先の休止が有効休止となる。親の切り替えで子の個別設定を書き換えない。階層移動後はIDと親IDから再計算する。欠損親で探索を終了し、循環も訪問済みIDで終了する。

共通の `DeckStudyEligibility` が有効休止ID集合を作る。`queueCards()` の学習用DTOには有効休止を反映し、復習・新規・混合、ホーム、日次上限の対象候補、通知、Widget、苦手練習・検索結果のカスタム練習から除外する。カードの個別停止と当日非表示は別に保持する。履歴と当日の達成・使用済み新規枠は過去の確定回答として残す。

復習予測と現在の記憶指標にも同じ休止判定を使う。統計の過去の回答履歴は休止によらず集計し、休止デッキも統計スコープに選べる。

ホームの対象カードがすべて休止中、選択したデッキが休止中、または中断セッションが休止中なら説明とデッキ管理への導線を表示する。再開時は元の期限を過ぎたカードがまとめて復習対象になることを案内する。

## 学習途中と保存

操作前に入力バッファを保存する。現在のカードが休止された場合、セッション、回答下書き、並べ替え下書き、Undo参照を保持し、計時を止める。提示・採点・セッション再開を止め、デッキ再開後に元の下書きから続ける。ホームでは完了と判定しない。休止画面からホームへ戻る操作も下書きを保持する。

Undoは確定回答を戻せるが、休止カードは提示しない。休止した祖先の下へデッキを移動した場合も計時を止める。別の学習を開始するときは既存のセッション置換確認を使う。

休止設定の保存は既存transactionを使い、失敗時はrollbackする。保存失敗と保存後の画面更新失敗は別メッセージ。保存後に既存のmutationRevision、ホーム・通知・Widget・統計・予測・ライブラリの更新経路を使用する。

## データ互換性

- V1〜V5のモデルは固定し、V6でDeckにoptional Boolの保存属性 `studyPaused` を追加。nilは学習中と解釈する。既存の軽量移行計画へV5→V6を追加し、起動前のMigrationRescueを維持する。ストアの削除・初期化は行わない。
- 完全バックアップはoptional `isStudyPaused` を保持。旧バックアップで属性が欠落した場合は学習中として復元する。
- `.studydeck` v1はコンテンツ交換のためローカル休止設定を出力しない。新規取込デッキは学習中。既存デッキへの取込は休止設定を変えず、休止した親の下への取込は有効休止となる。
- 切り替えでカードUUID、ノートUUID、FSRS payload、dueDate、ReviewLog、個別停止を変更しない。再開時も期限の自動補正を行わない。

## 性能と検証

デッキの有効休止は親ID表からメモ化して計算する。カードごとの祖先fetchは行わない。学習操作内で集合と既存のキュー投影を再利用し、transactionとrollbackで破棄する。FSRS payloadの既存デコードキャッシュを保持する。現在カードの提示・ホーム判定も投影済みの休止フラグを使う。

iPhone 17 Pro / iOS 26.5シミュレーターで関連22件を確認（休止5件、旧V1〜V4移行4件、通知5件、Widget8件）。V5→V6移行、再起動、現行・旧バックアップの本番復元経路、下書き・Undo・保存失敗、階層・件数・期限・インポートを確認する。3,000枚テストはキュー投影再利用と追加FSRSデコードなし、5秒以内の大まかな退行チェックを行う。Debugビルドも実施。

実機UI、通知受信、Widgetホーム画面表示、実データでの復元は未検証。性能はシミュレーターでの軽量確認で、Instruments計測は行わない。
