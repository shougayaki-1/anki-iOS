# Issue #9 — 学習統計の集計定義

## 「回答」とセッション進捗（Issue #55 との整合）

- **回答回数** = 確定・保存済み `StudyReviewLog` の件数。FSRS の Again/Hard/Good/Easy 評価を保存できた回数のみ数える。同一カードを同じ日に短期反復しても**回答ごとに1件**。
- **ユニークカード数** = 対象期間内に回答ログを持つ `cardID` の重複排除件数。セッション上限「20問」の代用にはしない。
- Undo によってログが実際に削除されると、回答回数と各指標から1件減る（同一カードに別のログがあればユニーク枚数は変化しない）。保存失敗・ヒント閲覧・解答表示・文章並び替え操作・未確定の正誤判定は計上しない。
- 新規／復習 = 各ログの `wasNew` を利用。新規回答後の同一カードに対する再回答は別ログとしてカウントし、そのログの `wasNew` に従う。
- セッション回答数は**そのセッション中**の確定回答回数、統計の回答数は**選択した期間内**の全セッションの確定回答回数。日次目標は**その学習日のユニーク枚数**。3つは独立し、統計がセッションの残り問題数・設定済み上限を変更しない。
- 4段階の評価件数、回答時間は同じ確定ログに基づく。回答時間は負数を0に丸め、推移では分単位（小数1桁）、全履歴の合計は整数分切り捨て表示。

## 期間とタイムゾーン

- 学習日の切替は設定の `dayStartHour`（初期4:00）。既存の `StudyDay.interval(containing:)` と同じ判定を利用。ログ日時が境界前なら前学習日、境界時刻以降なら当学習日。終了日付が未来のログ（`reviewedAt > now`）は表示しない。
- 日グラフ: 現在の学習日を含む直近30学習日。週グラフ: 地域の `Calendar` で区切る直近12週。月グラフ: 同じ `Calendar` の直近12暦月（いずれも今の期間を含む）。週/月への割り当ては実時刻の0時ではなく**学習日に属する暦日**に基づく。
- DST・時差の変化を固定秒数で処理せず、`Calendar` の日／週／月操作で期間境界を求める。時刻やタイムゾーン設定を変更すると過去ログの期間区分は再計算されるが、ログ自体は変更しない。
- **継続日数** = 直近の学習日が回答ありならそこから、回答なしなら前学習日から、回答ログのある学習日を連続して数える。期間グラフの30日制限に依存しない。

## 対象カードとフィルター

- 「すべてのデッキ・タグ」では削除されたカードを含め**全回答ログ**を集計する。削除済みカードのログはもともとのカードとの紐付けを失う場合があるため、デッキ／タグ別では再配分せず除外する。全体画面には所属不明ログ件数を表示する。
- デッキ指定では現在の `Deck.parentID` のデータから**選択デッキ＋全子孫**を対象にする。デッキ管理画面の階層表示・並び替え・編集処理は変更しない。
- タグ指定では選択したタグを**すべて持つ**カードを対象にする。デッキとタグは AND 条件。統計フィルターはホームの `LearningScope` と独立。
- ログ自体にデッキ／タグの歴史的スナップショットが存在しないため、カード／ノートが現在残っている場合の**現在の所属**による過去ログの再分類となる。デッキ移動／タグ更新を過去の所属まで復元した統計と表現しない。
- 期間内ユニークは**期間ごと**に計算。週/月ユニークを日次ユニークの合計で代用せず、期間全体の `Set<UUID>` で計算する。各期間のユニーク棒を合計すると重複が生じうる。

## 予測と現在値

- **予測保持率** = 現在存在し、停止されておらず、FSRS上で「new」ではないカードのFSRS-6現在時刻の予測想起確率の単純平均。0〜1の有限値のみ採用。復習で実測した正解率／評価Good率とは区別する。
- **期限超過** = 現在存在し、停止されておらず、FSRS上で「new」ではなく、`dueDate < now` のカード枚数。学習履歴の回答回数とは無関係。フィルター選択時は現在所属で絞り込む。
- 停止／削除済みカードは現在の予測・期限超過には含めないが、確定した過去回答ログは全体の履歴として保持する。

## パフォーマンス・確認

- `StudyStore.reload()` から履歴全走査を除去。`StatisticsReader` actorが専用SwiftData `ModelContext` で読み、集計結果だけを画面へ返す。結果は記録画面を開いた時／絞り込み更新時に再取得し、古い要求やバックアップ復元前の結果は世代番号で無効化。
- `Tests/UnitTests/StatisticsTests.swift`: 評価数とユニーク枚数、日境界、DST／タイムゾーン、週／月、フィルター、削除済みログ、12000件規模の集計。
- `Tests/IntegrationTests/StudyRepositoryTests.swift`: 独立Reader、子孫デッキフィルター、ノート削除後の履歴を確認。
- Xcode環境で追加確認: iPhone SE相当／最大Dynamic Type／ダークモード／VoiceOverでグラフの補足・全期間の数値を取得できること、1万件以上の実データ相当で学習評価保存が統計処理の完了を待たないこと、バックアップ復元直後の再読み込みとグラフの視認性。
