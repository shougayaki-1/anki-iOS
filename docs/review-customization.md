# Issue #5：学習画面の表示とジェスチャー

## 記述式回答の下書き保存（Issue #154）

文字入力はセッションの画面状態へ即時反映し、最後の入力から600ms後に保存する。答え表示・回答方式変更・評価・Undo・中断・画面離脱・非アクティブ移行では、未保存入力を先に保存する。評価は最新入力の保存に失敗した場合に進めず、入力を保持して「入力の保存を再試行」を表示する。画面の再取得で未保存の最新入力を古い下書きに戻さない。

保存先はセッションIDとカードIDで確認し、取消済みの遅延タスクは次カードへ書き込まない。Undo後は既存仕様どおり回答欄を空に戻す。入力後600ms以内にOSの強制終了が発生し、ライフサイクル通知も届かなかった場合、その区間の未保存入力の復元は保証しない。

## 設定と互換性

設定の「学習画面」で変更する。文字サイズは標準／大きめ／特大、画像は標準／コンパクト／非表示、解答を先に表示、アニメーションON/OFFを選べる。文字はSwiftUIの意味付きフォントを使い、端末のDynamic Type設定も反映する。解答を先に表示する設定でも、答え表示前には解答を見せない。画像マスクは学習に画像が必要なため常に表示する。コンパクトは通常の添付画像を最大180ptで表示する。

既存追加設定のJSONに任意のreviewAppearanceを追加し、DBスキーマを変更しない。旧JSONでは標準表示、スワイプOFF、問題→解答、アニメーションON。設定変更はUUID・FSRS・復習期限・履歴を変更しない。再起動と完全バックアップ・復元で保持する。不正な列挙値はJSONデコード時に拒否する。

## スワイプ

初期値OFF。ON時には固定評価バーの直上に「スワイプ操作を開く」と現在の方向ガイドを常時表示する（Issue #150）。入口を押すと260pt以上の専用領域を展開し、もう一度押すと閉じる。本文の長さに関係なくスクロールせずに開ける。大きな領域を常設せず、通常は本文の閲覧スペースを優先する。展開中も評価ボタンを維持し、本文は残った領域で末尾までスクロールできる。入力欄へフォーカスするとパネルを閉じ、キーボード用のスペースを確保する。次カード・Undoでも方向ガイドを現在の表示状態へ更新する。本文、画像、入力欄をスワイプしても評価しない。既存の答え表示、4評価、中断、Undoを保持する。

| 状態 | 方向 | 動作 |
|---|---|---|
| 答え表示前 | 右 | 答え表示 |
| 答え表示後 | 左 | Again |
| 答え表示後 | 下 | Hard |
| 答え表示後 | 右 | Good |
| 答え表示後 | 上 | Easy |

専用領域に触れている間だけ本文スクロールを止め、指を離す／キャンセルすると自動的に戻す。終点の実移動が96pt以上、主要軸が副軸の1.5倍以上のときだけ確定する。予測移動量は使わない。短い動き・曖昧な斜め・元へ戻す操作は確定しない。開始時のカードと表示状態を保持し、途中で状態が変わった操作は無効。確定操作の間は0.6秒空ける。表示・評価は指を離した後に既存StudyStoreを呼ぶ。

VoiceOver使用中は専用領域を表示せず標準ボタンを使う。Reduce Motionが有効な場合はアプリ内アニメーションONより優先して無効にする。

- 特大文字の設定入力を追加で確認し、通常の設定画面とともにスクリーンショット・可視要素監査を保存した。
- iPhone 15 Pro／iOS 27.0.1：バックアップ4件・設定再起動保持・色／アイコン検証が成功。表示設定・再起動・解答優先、特大文字設定、表示名・デッキキャンセル・検索の実機UIが成功。スワイプOFF／ON・短い動き・誤方向・4評価・Undo・設定の再起動保持も最終実機テストで成功（81.752秒）。最終実機選択実行は結合6件・UI3件の計9件すべて成功。

- 実機のVoiceOver音声・触覚、システムReduce Motion・通信遮断の再確認はIssue #3／#4の残件。カメラや通知タップの未達を、このPRの成功に含めない。

## 操作中のフィードバック（Issue #151）

PR #171の固定バーから開く専用パネルを前提とする。指の移動に応じてアイコンが最大24pt追従し、距離の進捗と「移動中：候補」を表示する。96pt・方向優位1.5倍・0.6秒の確定間隔を満たすと「離すと候補」とチェックへ切り替わる。100%は操作の準備状態で、保存完了ではない。解答前は右の答え表示、解答後は4評価を候補とする。

確定可能へ初めて入った時だけ選択触覚を出す。72pt未満まで戻した時に再び発火可能になり、再発火は最低0.3秒空ける。斜めや方向変更だけでは触覚を連打しない。戻して離す、専用領域外へ出る、カード・解答状態・回答方式の変更、Undo、中断、編集、手書き、非アクティブ化、ジェスチャー取消では準備状態を破棄する。

準備触覚があるスワイプでは通常の公開・評価触覚を重ねない。目標達成の触覚とボタン操作の触覚は保持する。保存失敗では成功触覚を出さず従来のエラーを表示する。触覚オフでも文言・チェック・進捗で状態が分かる。Reduce Motionではアイコンの追従移動を抑え、VoiceOverでは標準ボタンを使う。実機での触覚感触・日本語入力や手書きとの操作感は別途手動確認が必要。
