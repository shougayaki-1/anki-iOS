# タイピング回答の任意保存（#10）

設定 → 回答の保存設定で「評価時の回答本文を保存」をONにします。初期値OFF。文字入力方式で4段階の自己評価を確定した回答だけを保存します。basic / 記述式 / 穴埋め / 画像カードでも、実際の回答方式が文字入力の場合に限ります。頭の中で回答・並び替えの回答は保存しません。

入力中のセッション下書きは、従来どおり再開用に一時保存されます。本設定は評価後に残す回答履歴の設定で、OFFなら評価後の本文を残しません。OFFに戻しても過去の保存済み本文は残り、保存期間または手動削除に従います。

## 閲覧・削除

記録 → 保存したタイピング回答で、回答時点の問題、自分の回答、模範解答、自己評価、時刻を表示します。カードを後で編集・移動・削除しても保存した内容は変わりません。未入力も未入力として記録します。採点は利用者の4段階自己評価で、AI採点は行いません。

保存期間は7日・30日（初期値）・90日・手動削除まで。経過日数は回答時刻から24時間単位で計算し、期限を過ぎた本文は起動・評価・履歴表示・バックアップ時に削除します。アプリが停止している間は実行せず、次の機会に処理します。期間を短くすると期限外の本文を削除します。

履歴の行をスワイプして個別削除できます。保存設定の「保存した回答本文をすべて削除」では確認後に全本文を削除します。本文の削除はカード、FSRS、評価履歴、回答回数、復習予定に影響しません。削除済み本文はUndoでも再生成しません。評価そのもののUndoは、その評価に結び付く本文も同じトランザクションで取り消します。既存仕様に従い入力欄は空に戻ります。

## プライバシー・検索・バックアップ

本文は端末内のSwiftDataに保存し、アプリから外部送信しません。通常のライブラリ検索や統計集計には本文を含めず、専用履歴画面内だけで問題・自分の回答・模範解答を検索できます。

完全バックアップには保存済み本文と設定を含めます。書き出したファイルは本文の削除や保存OFFにしても変わりません。個人情報を含むバックアップは利用者が管理・削除してください。古いバックアップの復元では過去の本文が戻ることがあります。回答保存対応版で復元してください。

Schema V5で本文用のSavedTypedAnswerモデルを追加し、V1〜V4の既存Deck/Note/Card/ReviewLogを変更せず軽量移行します。旧ストア・本文のない旧バックアップは保存OFFとして扱い、過去のタイピング回答は再生成しません。本文はReviewLog UUID、Card UUID、時刻、評価と照合してバックアップを検証します。保存・削除・Undo・期間変更で失敗した場合はDBを巻き戻します。FSRSのpayload・ライブラリログに本文は混ぜません。
