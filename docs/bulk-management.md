# Issue #6：カード選択とノート一括管理

## 操作

ライブラリ上部の「ライブラリ操作」メニューから「カードを選択」で複数選択する。通常モードには下部操作バーを表示しない。選択中は上部に件数と「完了」、下部に選択メニューと一括操作を表示する。上部のカード追加・一括登録・OCRの操作は維持する。表示中を全選択・解除でき、検索を変えると選択を解除する。完了・画面離脱・処理成功後の結果を閉じると通常モードに戻る。一括操作のキャンセル・スワイプ閉じ・エラーでは選択を保持する。停止／再開は選択カードのみを変更する。デッキ移動・タグ追加／除去・削除はノート単位で行うため、選択していない兄弟カードも対象となる。

一括操作のプレビューには選択枚数、対象ノート／兄弟カード数、実際に変わる件数、移動先・タグ・対象の問題と元デッキを表示する。すでに指定状態なら変更対象ゼロと示し、適用しない。削除には別の確認が必要。

## データ保全

- 新しいDBモデル・スキーマは追加しない。UUID、カードのFSRS・期限、ReviewLogを非削除操作で保持する。
- プレビューは対象ノート／カード／保存された関連下書きの値を保持し、確定直前に再取得して比較する。対象消失、内容変更、兄弟カード追加、下書き変更、移動先の消失などは再確認を要求する。
- すべての変更を既存の単一save＋rollback処理で確定する。ノート／カードごとの部分保存や部分成功は行わない。
- タグは既存の正規化規則（空白・大文字小文字・アクセント）で重複を防ぐ。移動とタグ変更は保存された関連編集下書きにも適用し、未保存の問題・解答を保持する。
- ノート削除は兄弟カードと関連編集下書きを削除する。過去の履歴は保持する。削除対象のセッション参照・Undo・既出カード参照を整理し、新規作成用の下書きは保持する。画像ファイルをこのDB操作の途中で削除しない。
- DB確定後に画面再読込だけが失敗した場合も、確定済みの件数を表示して再起動を案内する。
