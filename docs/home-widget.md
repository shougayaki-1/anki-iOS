# ホーム画面ウィジェット

小・中サイズに、全デッキの復習待ち枚数と当日の学習目標進捗を表示する。中サイズは利用可能な新規枚数と回答回数、復習・進捗へのリンクも表示する。全体タップはホームへ移動する。復習中は既存の中断・再開確認を通る。

本体だけがSwiftDataを読み、App Group `group.dev.shoug.AnkiIOS.widgets` の `progress-v1.json` に集計結果を原子的に保存する。拡張にはSwiftData、FSRS、問題文、答え、デッキ名、カードID、画像を渡さない。表示件数と進捗はprivacySensitiveを指定する。ロック画面用サイズは提供しない。

回答・Undo・編集・取込・設定変更等による本体の再読み込み時と、ホームの日付・期限更新時にスナップショットを更新する。タイムラインは保存済み期限と学習日の境界を最大120件、約8日先まで含む。期限が多い場合は最初の未収録期限で失効し、古い件数を出し続けない。未来に回答したと仮定した予測ではない。時間帯の変更、期限切れ、ファイル破損・未取得ではアプリを開く案内を表示する。

WidgetKitへの更新要求は即時反映を保証しない。更新頻度や端末ロック中の保護ファイルの読み取りはOSが管理する。保存時刻を表示し、設定から再同期も可能。共有の失敗は設定に表示し、本体DBの保存・学習を継続する。App Groupは本体と拡張両方のentitlementsに設定する。実機配布時は両方の署名プロファイルで当該グループを有効にする。

## 検証

通常サイズのiPhone 17 Proシミュレーターでアプリ・拡張のビルド成功。単体172件成功（既存の実機専用1件スキップ）。共有ファイルの破損・サイズ上限、書込失敗、世代競合、学習日境界・夏時間・時間帯変更・期限切れ・兄弟カード除外・新規制限と正式キューの一致を検証した。

Macがロックされていたため、ホームへのウィジェット追加と実表示の操作確認は未実施。iOS 17実行端末と実機での更新遅延、ロック中表示、署名済みApp Group共有も未確認。実装PRはDraftとし、これらを配布前の確認項目とする。拡大文字・iPhone SEのテストは省略。

デッキ休止は親から継承した有効状態も含めて共通キュー投影で除外する。休止切替後は保存成功を確認して既存の通知・Widget更新を行う。過去の学習件数・達成は保持する。詳細は [デッキ学習休止仕様](deck-study-pause.md)。
